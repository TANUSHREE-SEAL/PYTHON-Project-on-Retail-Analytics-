# PYTHON-Project-on-Retail-Analytics-
# 📊 Retail Analytics Dashboard

An interactive Retail Analytics Dashboard built with **Python, Streamlit, Pandas, and Plotly** to analyze sales performance, customer behavior, product trends, and regional insights using interactive visualizations and filters.

---

## 🚀 Live Dashboard - https://jxuvqe76bgfywbebgx2wif.streamlit.app/

---

## ✨ Features

- 📈 Executive KPI Dashboard
- 🔍 Interactive Filters
- 💰 Sales & Revenue Analysis
- 🛍️ Product Performance Analysis
- 👥 Customer Insights
- 🌍 Regional Performance Analysis
- 🚚 Shipping & Fulfillment Analysis
- 📊 Interactive Plotly Charts
- 📂 Transaction-Level Data Explorer

---

## 📊 Dashboard Modules

### 📈 Sales & Trends
- Monthly Revenue & Order Trend
- Average Order Value Trend
- Order Status Distribution
- Sales by Weekday

### 🛒 Products
- Revenue by Category
- Top 10 Sub-Categories
- Best-Selling Products
- Discount Impact Analysis
- Category × Region Heatmap

### 🌍 Regions & Fulfillment
- Revenue by Region
- Orders by Region
- Ship Mode Analysis
- Top Revenue States
- Regional Order Status

### 👥 Customers
- Revenue by Customer Segment
- Customer Signup Trend
- Top Customers
- Repeat vs One-Time Customers

### 🔍 Deep Dive Analytics
- Unit Price vs Units Sold
- Average Discount by Category
- Days from Signup to First Purchase
- Interactive Data Explorer
